# Agentic AI Learning Roadmap

A simple, step-by-step roadmap for software testers, developers and IT professionals who want to learn **Generative AI and AI Agents** in 2026.

## Who is this for?
- Testers and developers with 2–15 years of experience
- IT professionals moving into AI roles
- Anyone preparing for AI engineer, Forward Deployed Engineer (FDE) or AI tester roles

---

## The Roadmap

### Stage 1: AI Basics (1–2 weeks)
- What is a Large Language Model (LLM)?
- Tokens, context window and temperature (in simple words)
- Strengths and limits of AI: hallucinations, bias, outdated knowledge
- Practice: use an AI assistant daily for emails, summaries and test ideas

### Stage 2: Prompt Engineering (1–2 weeks)
- Clear instructions, examples and output formats
- Role prompts and step-by-step reasoning
- Asking for structured output (tables, JSON)
- Practice: write prompts that turn a requirement into test cases

### Stage 3: Working with AI in Code (2–3 weeks)
- Basic Python
- Calling an AI model through an API
- Handling responses and errors
- Practice: build a small script that summarises a text file

### Stage 4: AI Agents (3–4 weeks)
- What makes an "agent": goal, planning, tools, memory
- Tool use: letting AI call APIs, read files or search
- Model Context Protocol (MCP): a standard way to connect AI to tools and data
- Practice: build an agent that reads test results and drafts a bug report

### Stage 5: RAG and Company Data (2–3 weeks)
- Retrieval-Augmented Generation (RAG) explained
- Splitting documents and searching them
- Keeping answers faithful to the source
- Practice: a chatbot that answers questions from your team's documents

### Stage 6: Testing, Safety and Deployment (2–3 weeks)
- Testing AI: accuracy, hallucinations, prompt injection, bias
- Monitoring cost and speed
- Deploying an AI app for real users
- Practice: write evaluation tests for your Stage 5 chatbot
